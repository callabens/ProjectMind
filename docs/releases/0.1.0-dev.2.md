# ProjectMind 0.1.0-dev.2 preview candidate

This is a development preview for the npm `next` tag, not a stable release.

## Highlights since 0.1.0-dev.1

- polished evidence-first landing page and hosted read-only MCP documentation
- deterministic binding suggestions and `projectmind doctor`
- LCOV-backed source coverage bindings
- bounded GitHub PR comments with previous-ProofPack regression summaries
- `proof validate`, `proof diff` and `proof history` workflows
- authentication, API-contract and dependency-boundary intent templates
- non-executing `quickstart` onboarding
- Provider SDK v1 scaffold generation
- Python AST/import scanning and pytest JUnit evidence
- Engineering Memory Lite and stronger cross-platform lifecycle coverage

## Trust boundary

`VERIFIED` still means only that declared checks passed against the recorded repository state. This candidate does not add artifact signing, hermetic execution, a general security guarantee or automatic approval of suggested bindings.

## Candidate gate

Before publication:

1. Run `pnpm validate`.
2. Run `pnpm pack:repro` and the package smoke test.
3. Run `pnpm release:check --channel preview --name @callabens/projectmind`.
4. Inspect the tarball and publish explicitly with the `next` tag from the authorized npm maintainer account.
