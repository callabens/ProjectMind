# ProjectMind 0.1.0-dev.3 preview candidate

This is a development preview for the npm `next` tag, not a stable release.

## Highlights since 0.1.0-dev.2

- one-call `projectmind_get_overview` MCP summary for project context, active intent and historical verification status
- fail-closed `projectmind integration check` for Claude Code, Codex, Cursor and VS Code
- safe `PATH` resolution that detects a missing ProjectMind executable without launching configured commands
- stdio and authenticated HTTP compatibility coverage for the new overview contract

## Trust boundary

The overview and integration checks are read-only. They do not run repository verification commands, refresh evidence, set a verdict or launch an MCP command found in configuration. `VERIFIED` retains its existing evidence-bound meaning.

## Candidate gate

Before publication:

1. Run `pnpm validate`.
2. Run `pnpm pack:repro` and the package smoke test.
3. Run `pnpm release:check --channel preview --name @callabens/projectmind`.
4. Inspect the tarball and publish explicitly with the `next` tag from the authorized npm maintainer account.
